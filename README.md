# Weekly Learning Plan

A concise, week-by-week plan to structure learning. Each week includes focus, objectives, core topics, suggested resources, activities, and a deliverable.

---

## Week 1 — Foundations
- Focus: Overview & goals, setup environment
- Objectives: Define goals, install tools, learn core terminology
- Topics: Workflow, version control basics (git), editor shortcuts
- Resources: Official git docs, editor quickstart
- Activities: Setup repo, commit initial notes
- Deliverable: Project repo with README and learning goals

## Week 2 — Core Concepts
- Focus: Fundamental theory and concepts
- Objectives: Understand main primitives and patterns
- Topics: Data types, control flow, functions/modules
- Resources: Language/tutorial official docs
- Activities: Implement small examples
- Deliverable: 3 mini examples covering core concepts

## Week 3 — Practical Exercises
- Focus: Hands-on practice
- Objectives: Apply basics to small problems
- Topics: Problem solving, debugging, testing basics
- Resources: Kata sites, testing guides
- Activities: Solve 5 problems, write tests
- Deliverable: Solutions repository with tests

## Week 4 — Tooling & Workflow
- Focus: Toolchain and productivity
- Objectives: Master build tools, linters, formatters
- Topics: CI basics, automated tests, code style
- Resources: CI docs, linter guides
- Activities: Add linter and CI pipeline
- Deliverable: Passing CI on repository

## Week 5 — Intermediate Topics
- Focus: Deeper language features
- Objectives: Learn intermediate patterns and libraries
- Topics: Asynchronous patterns, modules, OOP/FP concepts
- Resources: Official intermediate guides
- Activities: Build a medium-sized example
- Deliverable: Feature-complete example project

## Week 6 — APIs & Integration
- Focus: Working with external systems
- Objectives: Consume and design simple APIs
- Topics: HTTP, REST, JSON, authentication basics
- Resources: API docs, Postman tutorials
- Activities: Build client and simple API
- Deliverable: Small API with client demo

## Week 7 — Data & Persistence
- Focus: Storing and retrieving data
- Objectives: Use databases and data models
- Topics: SQL/NoSQL, ORMs, migrations
- Resources: DB tutorials
- Activities: Integrate DB into project
- Deliverable: App with persistent storage

## Week 8 — Testing & Quality
- Focus: Reliability and correctness
- Objectives: Write robust tests and use CI effectively
- Topics: Unit, integration, end-to-end tests, code coverage
- Resources: Testing framework docs
- Activities: Expand test coverage
- Deliverable: Test suite with coverage report

## Week 9 — Performance & Optimization
- Focus: Efficiency and profiling
- Objectives: Identify bottlenecks and optimize
- Topics: Profiling, caching, complexity analysis
- Resources: Profiling tools guides
- Activities: Profile project and optimize hotspot
- Deliverable: Optimized module and before/after metrics

## Week 10 — Security & Best Practices
- Focus: Secure and maintainable code
- Objectives: Learn basic security practices
- Topics: Secrets management, input validation, dependency updates
- Resources: Security checklists
- Activities: Run dependency scans, fix issues
- Deliverable: Hardened project and checklist

## Week 11 — Deployment & Scaling
- Focus: Release and operate software
- Objectives: Deploy to an environment, basic ops
- Topics: Containers, cloud basics, monitoring
- Resources: Container/cloud quickstarts
- Activities: Deploy app and add basic monitoring
- Deliverable: Live deployment with health checks

## Week 12 — Review & Capstone
- Focus: Consolidation and showcase
- Objectives: Review learning, finalize a capstone project
- Topics: Documentation, presenting work, next steps
- Resources: Presentation tips, portfolio guides
- Activities: Polish project, prepare demo
- Deliverable: Capstone project and presentation notes

---

Tips:
- Estimate 6–12 hours/week; adjust pace to personal schedule.
- Keep weekly retrospectives: what went well, what to change.
- Track progress in the repository README.
