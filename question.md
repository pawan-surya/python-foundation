🚀 Beginner Level Questions (Basics, Variables, Data Types)
1. Variables & Data Types

Write a program to swap two numbers without using a third variable.

Take user input for name and age, and print "Hello <name>, you are <age> years old."

Convert a string "123" into an integer and add 10.

Check the data type of each variable: a=10, b=10.5, c="Python".

2. Operators

Write a program to calculate the area of a circle when the radius is taken as input.

Find the largest of three numbers using only logical operators (no built-ins like max()).

Write a program to check if a number is even or odd.

3. Conditional Statements

Take a number and print whether it's positive, negative, or zero.

Write a program that checks if a character is a vowel or consonant.

Ask the user to enter a year and check if it's a leap year.

4. Loops

Print numbers from 1 to 100 using a loop.

Print the multiplication table of any number entered by the user.

Count how many digits are in a number.

Reverse a number using a while loop.

5. Strings

Check if a string is a palindrome.

Count vowels and consonants in a given string.

Remove all spaces from a string.

Find the frequency of each character in a string.

🧩 Intermediate Level Questions
1. Lists

Find the largest and smallest number in a list.

Remove duplicates from a list without using set().

Take 10 numbers from user input and store them in a list. Print the sum and average.

2. Tuples

Convert a tuple into a list and add an item.

Count how many times an item appears in a tuple.

3. Dictionaries

Count how many times each word appears in a sentence using a dictionary.

Create a dictionary of student names and marks, and print the student with the highest score.

Merge two dictionaries.

4. Functions

Write a function to find the factorial of a number.

Write a function that returns the Fibonacci series up to n terms.

Create a function to check if a number is prime.

5. File Handling

Write a program to read a text file and count the number of lines.

Write a program to copy the contents of one file to another.

Write a program to find how many times a word appears in a file.
